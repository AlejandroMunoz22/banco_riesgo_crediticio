# Credit Risk & Default Prediction Pipeline (End-to-End)

Data engineering, statistical modeling, and artificial intelligence project applied to bank credit risk using the relational dataset from **Home Credit Default Risk**.

##  Tech Stack
* **Relational Database:** Microsoft SQL Server (T-SQL)
* **Big Data & ETL:** Apache Spark (PySpark)
* **Statistical Analysis & Vectorization:** Python (NumPy, Pandas, SciPy)
* **Machine Learning:** Scikit-Learn / XGBoost
* **Methodology:** CRISP-DM + Cookiecutter Data Science

## Project Architecture
* `sql/`: DDL scripts, bulk ingestion, and analytical T-SQL queries.
* `data/`: Multi-layer local storage (`raw`, `interim`, `processed`) - *Ignored in Git for security*.
* `src/`: Production Python modules.
* `notebooks/`: Statistical exploration (EDA) and prototyping.
